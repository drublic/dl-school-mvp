Pre-push Runs OpenSpec.

1 Discover 2 Design 3 Build 4 Verify 5 Release

Tonight we name it. Husky on the repo, OpenSpec on every git push.

$ npm install --save-dev husky
$ npx husky init
$ echo "openspec validate --all --strict --no-interactive" > .husky/pre-push
$ echo "openspec validate --archived --no-interactive" >> .husky/pre-push
--all --strict
Open changes and specs are well-formed. Warnings fail the push.
--archived
Every archived tasks.md is fully ticked. No half-finished delta in the truth.

Exit ≠ 0 → no push. Same hook then runs lint · typecheck · test — spec half, then code half.

Do not install live. husky init writes a pre-commit (npm test) and a prepare script — we add pre-push for OpenSpec. --no-interactive so validate never prompts. --archived is what the CLI docs call handy for pre-commit; we put both on pre-push. Gates 1–2 just ran in the app. Next: agentic commit and push.
