A Prompt Is Not a Spec.

Plan mode is not enough. Intent has to live somewhere the next session can read.

Chat dies
Context vanishes. The next session does not know your intent. “We already said that…” helps no one.
The repo doesn’t
A spec in git is truth for you, for the agent, and for the next person. Reviewable. Diffable. Archivable.

That’s why spec-driven: write the intent down, then point the agent at it, then update the spec when you learn.
